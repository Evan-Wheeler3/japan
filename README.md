# Yoake (working title)

A cozy first-person Japanese restaurant simulator. The player runs a small restaurant on a snowy mountainside overlooking the ocean, across a single night that ends in a signature sunrise over Mount Fuji.

This repository currently contains the pre-production game design & technical blueprint only — no game code has been implemented yet.

**Start here: [`BLUEPRINT.md`](./BLUEPRINT.md)** — the complete game design and technical specification: vision, gameplay systems, data architecture, technical stack recommendation, development phases, and the first implementation tasks.
